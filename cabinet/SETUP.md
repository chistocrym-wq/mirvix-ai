# Кабинет MIRVIX AI — запуск

Публичная кнопка в подвале → `/cabinet/` — страница входа для партнёров и сотрудников.

Сотрудник после входа видит ссылки на `/geo-live/` и `/audit/`. Партнёр входит в отдельную ограниченную область; доступа к GEO API у него нет. Старый маршрут `/geo/` перенаправляет к входу.

## Обязательные переменные Netlify

Настройте **Project configuration → Environment variables**, секреты должны быть доступны Functions и Deploy Previews:

- `MIRVIX_AUDIT_PASSWORD`: пароль команды (минимум 12 символов).
- `MIRVIX_PARTNER_PASSWORD`: **другой** пароль партнёров (минимум 12 символов).
- `MIRVIX_CABINET_SESSION_SECRET`: отдельная случайная строка длиной от 32 символов, ключ подписи cookie. Ни один пароль нельзя использовать как secret подписи.
- `OPENAI_API_KEY`: оплаченный ключ OpenAI API для реальных проверок (или `GEMINI_API_KEY`, `PERPLEXITY_API_KEY`).

Никогда не вставляйте значения в GitHub или чат. После установки переменных пересоберите PR Preview.

**Важно:** это стартовая авторизация, основанная на двух общих паролях и подписанной HttpOnly-cookie (8 часов). Она проверяется сервером и отделяет роли, но не заменяет индивидуальные учётные записи, MFA, аудит доступа и rate limiting. Для расширенного партнёрского кабинета с данными отдельных клиентов нужна полноценная база пользователей и контроль прав на каждый объект.

`/audit/` публичен как техническая демонстрация и не показывает историю или приватную аналитику.

Не публикуйте main до ручного тестирования авторизации, выхода, серверных API и реальных провайдеров.
