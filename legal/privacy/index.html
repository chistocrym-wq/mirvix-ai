2. Какие сведения могут обрабатываться

Сайт носит информационный характер. В чате MIRA посетитель может с отдельного согласия передать описание задачи внешнему сервису искусственного интеллекта для подготовки подробной формулировки обращения. Контактные данные рекомендуется сообщать только после подтверждения клиентом итогового описания; они не направляются в ИИ-сервис оформления текста. Голосовое распознавание может осуществляться сервисом браузера и регулируется также условиями его поставщика. На сайте есть форма подготовки заявки: введённые имя, контактные данные и описание проекта остаются в браузере до открытия почтового приложения посетителя. Сайт не отправляет их в Netlify Forms и не сохраняет на собственном сервере. При использовании MIRA посетитель может подтвердить отправку сформулированной задачи в Telegram команды MIRVIX AI. Содержимое подтверждённого обращения передаётся через серверную функцию Netlify в Telegram Bot API. При недоступности Telegram автоматическая передача не выполняется; сайт может предложить самостоятельно отправить письмо. Для фактической отправки обращения почтой посетитель самостоятельно отправляет подготовленное письмо. На сайте используется Яндекс Метрика (идентификатор счётчика 114153852) для статистики посещений, посещённых страниц, переходов по кнопкам и источников трафика. Загрузка счётчика происходит после добровольного согласия посетителя, которое можно отклонить. Для обычных публичных страниц при согласии может включаться Вебвизор; на страницах кабинета, проверки и аудита запись действий Вебвизором отключена, а адреса передаются без параметров запроса. При работе Метрики данные посещения могут передаваться Яндексу по правилам сервиса. Сайт не передаёт в цели Метрики введённый текст формы, ключи API, электронную почту и другие значения полей. Источник перехода из ИИ определяется только по доступному referrer или UTM, поэтому некоторые посещения могут оставаться неопределёнными. Выбор сохраняется в браузере, а изменить его можно через ссылку «Настройки аналитики» внизу страницы.

Если вы самостоятельно напишете нам по электронной почте или обратитесь в мессенджере, мы можем получить те сведения, которые вы отправите: имя, контактные данные, текст обращения и прикреплённые файлы. При посещении сайта хостинг-провайдер может обрабатывать технические данные соединения и журналы доступа в рамках предоставления инфраструктуры.

Данные используются, чтобы ответить на обращение, обсудить задачу, подготовить предложение, заключить и исполнить договор при необходимости, а также обеспечить стабильную и безопасную работу сайта. Обработка осуществляется на применимых законных основаниях, в том числе в связи с обращением посетителя и при наличии необходимого согласия.

Мы не рассматриваем простой просмотр сайта как автоматическое согласие на маркетинговые рассылки.

4. Мессенджеры и внешние сервисы

Кнопки Telegram, WhatsApp и MAX ведут на сторонние сервисы. Их правила, настройки конфиденциальности и обработка данных регулируются также документами соответствующих сервисов. При переходе вы покидаете сайт MIRVIX AI. Прямая ссылка в MAX пока не подключена — кнопка открывает веб-версию приложения.

Мы ограничиваем доступ к полученным обращениям, используем их для заявленных целей и храним не дольше, чем это требуется для переписки, исполнения обязательств и соблюдения применимого закона. Для работы сайта используется хостинг Netlify; передача данных сторонним сервисам возможна только в объёме, необходимом для работы соответствующего канала и в соответствии с применимым законодательством.
