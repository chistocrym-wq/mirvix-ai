# Подключение MIRA к Telegram (MIRVIX AI)

Новый интерфейс MIRA показывает клиенту полный текст задания, спрашивает только «Хотите что-нибудь добавить?» и отправляет через стрелку ➤ после подтверждения передачи данных.

## Подключение личного Telegram

1. В Telegram откройте официального [@BotFather](https://t.me/BotFather). Команда /newbot создаст **отдельного** бота для заявок MIRVIX AI. Это может быть, например, MIRVIX Requests. Токен храните в секрете, не публикуйте в GitHub или переписке.
2. Найдите созданного бота и нажмите **Start**, затем отправьте ему сообщение, например `/start`.
3. Узнайте числовой `chat.id` своего диалога с ботом. Один из вариантов — вызвать в своём браузере `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` после отправки сообщения и прочитать поле `result[].message.chat.id`. Не пересылайте URL с токеном никому. При использовании privacy-инструментов и других ботов для ID не передавайте им закрытые данные.
4. В существующем Netlify проекте MIRVIX AI перейдите в **Project configuration → Environment variables** и добавьте две переменные **с областью Functions**: `MIRA_TELEGRAM_BOT_TOKEN` (токен бота) и `MIRA_TELEGRAM_CHAT_ID` (числовой chat.id). Значения не добавляйте в код сайта.
5. Запустите новый deploy проекта в Netlify, чтобы Functions увидели переменные, и проверьте доставку тестового обращения. Проверить, настроена ли доставка без раскрытия секретов, можно на `https://mirvixai.com/api/mira-submit` (возвращает только `deliveryConfigured`).

**Важно:** Telegram не может отправлять сообщения пользователю только по номеру телефона: сначала пользователь должен открыть диалог с конкретным ботом. Номер +7 960 253 79 79 — это контакт, а не Telegram chat ID.

Доставка работает только после согласия клиента. При неполадках MIRA показывает текст заявки и ссылку на письмо вместо ложного сообщения об успехе. Пока переменных нет, `deliveryConfigured: false` и автоматических уведомлений нет.

ИИ-формулировка: отдельный обработчик `/api/mira-brief` при доступном `OPENAI_API_KEY` и `OPENAI_BASE_URL` перефразирует слова пользователя без потери конкретных требований; если ИИ недоступен, показывается полностью исходный текст. Личные контакты не отправляются в ИИ.
