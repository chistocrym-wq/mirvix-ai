# MIRVIX AI

Официальный сайт MIRVIX AI. Статический сайт, размещение: GitHub + Netlify. Основной домен: `mirvixai.com`.

## Настройка Netlify

- Подключить репозиторий `chistocrym-wq/mirvix-ai`.
- Production branch: `main`.
- Build command: пусто.
- Publish directory: `.`.
- Перед подключением домена проверить сайт на временном адресе Netlify.
- Новые изменения делать через отдельные ветки и Pull Request / Deploy Preview. Объединять после одобрения владельца.

## Файлы сайта

- `index.html` — главная страница.
- `assets/` — логотипы и изображения.
- `robots.txt`, `sitemap.xml` — начальные SEO-файлы.

DNS домена и настройки почты не меняются при загрузке файлов в GitHub.
