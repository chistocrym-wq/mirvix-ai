# MIRVIX AI — набор инструментов видимости в ИИ

Основной сайт остаётся статическим. Административные инструменты открываются на `/cabinet/tools.html` (только после ввода секретного токена). Старый ручной прототип — `/cabinet/`.

## Функции
- Паспорт компании, список конкурентов, матрица коммерческих запросов.
- Ручной журнал проверок ChatGPT, Gemini, Perplexity, Copilot, Алиса AI с текстом ответа и источниками.
- **Опциональные** оплачиваемые API-запросы OpenAI Responses + web search, Perplexity Sonar, Gemini + Google Search grounding.
- Технический аудит публичного сайта: HTTP, HTML-метаданные, canonical, noindex, JSON-LD, robots.txt, sitemap.xml.
- Конкурентная аналитика, поиск запросов с упоминаниями конкурентов, чек-лист продвижения.
- Отчёт по периодам, печать в PDF через браузер, JSON и CSV экспорт.
- Серверное хранение через Netlify Blobs. В Deploy Preview **getDeployStore** изолирован от production. Production использует отдельный store; его не запускать до одобрения.

## Обязательная настройка Netlify (Environment Variables)
`MIRVIX_CABINET_TOKEN` — длинный случайный секрет (минимум 20 символов). **Не добавлять в репозиторий**. После его настройки открыть `/cabinet/tools.html` и ввести токен. Не использовать один и тот же токен с клиентами.

## Опциональные API-провайдеры
- `OPENAI_API_KEY` — OpenAI Responses API, поиск web_search. Опциональная настройка модели: `MIRVIX_OPENAI_MODEL` (по умолчанию `gpt-5.4`).
- `PERPLEXITY_API_KEY` — Sonar API. `MIRVIX_PERPLEXITY_MODEL` (по умолчанию `sonar`).
- `GEMINI_API_KEY` — Google Gemini API с поиском. `MIRVIX_GEMINI_MODEL` (по умолчанию `gemini-2.5-flash`).

Доступные модели, цены и лимиты меняются; проверяйте их в кабинетах провайдеров. Ключи хранятся только в Netlify, клиентскому JavaScript не передаются. **API-ответы не тождественны ответам потребительских приложений**. Вызовы выполняются только по явному нажатию кнопки, каждый отдельно с подтверждением.

## Честная аналитика
Автоматический статус найденного бренда определяется по совпадению названия/домена и должен проверяться человеком. Ошибка/таймаут не считаются отрицательным результатом. Индексация не подтверждается без Google Search Console, Bing Webmaster Tools или Яндекс Вебмастера. Загрузка robots/sitemap не доказывает появления в ИИ.

## Безопасность
- Вся серверная API-функция требует секретный токен. При его отсутствии доступ не разрешён.
- Preview и Production используют разные Blob Store.
- Аудитор отклоняет IP, localhost, типичные приватные адреса, необычные порты и перенаправления в такие сети; устанавливает лимиты размера и времени ответа.
- Для реального многопользовательского кабинета нужна индивидуальная авторизация с ролями, аудит логов и полноценная транзакционная база (Netlify DB/Postgres). Текущая версия — **администраторский кабинет для одной организации**, не клиентский SaaS.
- Поскольку GitHub/Netlify deployment может не проходить без настройки, проверяйте deploy logs перед публикацией.

## Проверка перед выпуском
1. Убедиться, что в Deploy Preview доступна `/cabinet/tools.html`.
2. Без токена API не отдаёт данные (401/503).
3. С токеном запрос `status` показывает доступные провайдеры и изоляцию Preview.
4. Проверить сохранение и повторное чтение проекта, аудит публичного сайта и экспорт.
5. Только затем при согласовании — рассмотрение merge в main.
