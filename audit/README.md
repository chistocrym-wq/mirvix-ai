# Экспресс-аудит MIRVIX AI

Страница `/audit/` проверяет публичные технические признаки сайта в режиме реального времени через Netlify Function `site-audit`.

Состав проверки: HTTPS, title, description, H1, canonical, lang, viewport, robots.txt, sitemap.xml, JSON-LD, Open Graph, явный noindex и правило OAI-SearchBot на главной странице.

Отчёт показывает технический процент среди проверенных критериев. Не заявляет видимость в ChatGPT, Алисе или иных ИИ.

Демонстрационный пример помечен как учебный; печать/PDF через браузер.

Для массового публичного запуска нужны rate limiting, устойчивый контроль SSRF/DNS-rebinding и мониторинг времени ответа, тесты внешних HTTPS-сайтов. В PR не заложены API-ключи Pixel Tools.

Production не изменять без подтверждения владельца.
