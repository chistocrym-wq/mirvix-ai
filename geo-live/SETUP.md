# MIRVIX GEO — запуск без Pixel Tools

## Состояние
Рабочие страницы: /audit/ (технический аудит) и /geo-live/ (собственный API-мониторинг). Инструмент делает по одному реальному запросу к API за каждую пару "вопрос + провайдер", анализирует упоминания и источники, показывает отчёт, экспортирует JSON.

**Не равен выдаче потребительских приложений ChatGPT, Алиса и Gemini.** Алиса пока не подключена. Результат зависит от даты, модели, места и формулировки запроса.

## Доступ Netlify → Project configuration → Environment variables
Скопируйте имена переменных, значения добавляйте только в интерфейсе Netlify, не в GitHub или чат:
- `MIRVIX_AUDIT_PASSWORD` — случайный секрет не короче 12 символов, ограничивает кабинет (защита от случайных посетителей, не полноценная авторизация).
- `OPENAI_API_KEY` — отдельный оплачиваемый ключ API OpenAI (не подписка ChatGPT).
- `GEMINI_API_KEY` — ключ Gemini Developer API (по желанию).
- `PERPLEXITY_API_KEY` — ключ Perplexity API (по желанию).

Начать можно только с пароля + одного из API-ключей. После сохранения — redeploy Deploy Preview PR №2. API-ключи не должны быть доступны frontend/browser, хранятся в серверных переменных.

## Пробная проверка
1. Откройте Deploy Preview → /geo-live/.
2. Введите пароль из Netlify и нажмите «Проверить подключения».
3. Укажите компанию, домен, город, 3–5 запросов без названия бренда.
4. Выберите один API, подтвердите платный запуск.
5. Сверьте полученные ответы, упоминания, ссылки; скачайте JSON/распечатайте PDF.

Важно: публичный гостевой доступ не включать. Перед широким запуском: добавить централизованные лимиты расходов/rate limiting, полноценную авторизацию, хранение истории, управление очередью и тест с реальными ключами. Система пока прототип, ее HTTP/API-интеграции не прошли e2e тест с оплачиваемыми секретами.
